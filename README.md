## 🚀 About Me

I'm an **AI/ML Engineer with 3+ years** of experience building and shipping **production-grade LLM systems at scale**. I specialize in **RAG architectures**, **Voice AI**, **distributed inference**, and **real-time conversational agents** — turning cutting-edge research into systems that actually work in the real world.

- 🏗️ Architected distributed LLM inference platforms serving **1M+ daily queries** on AWS EKS
- 🎙️ Built multilingual **Voice AI agents** using **LiveKit**, WebRTC, Twilio, OpenAI & Deepgram — automating **50K+ calls/month**
- ⚡ Reduced LLM inference latency **50%** (400ms → 200ms p95) and costs **30%** via GPTQ quantization & vLLM
- 📉 Cut hallucinations **40%** using hybrid Graph + Vector RAG on enterprise knowledge bases (10M+ docs)
